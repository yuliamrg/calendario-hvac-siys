Guía rápida

Cómo usar el calendario

  1. Importa la Base Operativa o crea una actividad nueva.
  2. Arrastra un cliente o una sede a una fecha del calendario.
  3. Haz clic en una tarjeta para revisar sus datos y actualizarla.
  4. Usa Pendiente para guardar actividades que todavía no tienen fecha.
  5. Para cambiar fechas, usa Mover, Duplicar o Ampliar.
  6. Usa la búsqueda y los filtros para encontrar tarjetas rápidamente.
  7. Descarga listados, imágenes o una copia del cronograma cuando lo necesites.
Para conservar tus datos

El cronograma se guarda en este navegador. Descarga una copia con regularidad si necesitas conservarla o llevarla a otro equipo.

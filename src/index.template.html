Guía rápida

Cómo usar el calendario

  1. Importa la Base Operativa o crea registros manuales.
  2. Arrastra un cliente o sede a una fecha, o usa Nueva actividad.
  3. Haz clic en una tarjeta para ver todos sus datos y cambiar su estado.
  4. Usa la casilla de cada tarjeta para seleccionar y mover varias a la vez.
  5. Descarga un respaldo JSON con regularidad.
Privacidad y persistencia

La aplicación funciona sin conexión. Sus datos se guardan en IndexedDB dentro de este navegador y no se envían a ningún servidor. La importación de Excel excluye campos personales y de contacto.
